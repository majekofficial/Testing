Solving two or three equations at once

Simultaneous equations are a set of equations that must all be true for the same unknowns. Type one equation per line, using straight-line (linear) equations only. The calculator solves systems with two, three or more letters, and for two letters it also draws the graph.

Why a solution is a crossing point

Each equation with two unknowns is a straight line. The solution of the pair is the point where the two lines cross. That is why there are three possible outcomes:

  • One solution: the lines cross once.
  • No solution: the lines are parallel and never meet. The calculator says the equations contradict each other.
  • Infinitely many solutions: both equations describe the same line. The calculator expresses one letter in terms of the other.

Worked examples

Elimination

x + y = 10 and x − y = 2. Add the equations: 2x = 12, so x = 6. Then y = 10 − 6 = 4. The calculator gives x = 6, y = 4.

Unequal coefficients

2x + 3y = 12 and x − y = 1. From the second equation x = y + 1. Substitute into the first: 2(y + 1) + 3y = 12, so 5y = 10 and y = 2, x = 3.

Three letters

x + y + z = 6, 2x − y + z = 3 and x + 2y − z = 2 have the solution x = 1, y = 2, z = 3. Check the first: 1 + 2 + 3 = 6.

Parallel lines

x + y = 2 and x + y = 5 cannot both be true. The result is “No solution”.

The same line twice

x + y = 2 and 2x + 2y = 4 are the same equation. Every pair with x = 2 − y works, so y can be any number.

Choosing a method by hand

  • Substitution works well when one equation already gives a letter, such as y = 3x − 1.
  • Elimination works well when coefficients match or can be made to match by multiplying an equation.
  • Graphing gives a picture and a rough answer, which is handy for checking.

Common mistakes

  • Typing the equations on one line. Use one line per equation.
  • Adding equations when the signs do not cancel the letter you want to remove.
  • Not checking the answer in both equations.
  • Including squares or products of letters. Those systems are not linear and are outside this tool.

If you only need one unknown, the Linear Equation Calculator is simpler. To find the line through two points, use the Slope Calculator. Word problems that produce two equations can be set up with the Word Problem Solver.

Frequently asked questions

How do I enter the equations?

Type one equation per line, for example x + y = 10 on the first line and x − y = 2 on the second.

How many equations do I need?

Usually one equation for each unknown. With fewer, there are infinitely many solutions.

Can it solve non-linear systems?

No. The equations must be straight-line (linear).

What does “the equations contradict each other” mean?

There is no set of values that makes every equation true. Graphically, the lines are parallel.
