Analyse a discrete frequency distribution

A frequency table records how often each value occurs. This calculator accepts a list of discrete values and, optionally, a matching list of frequencies. It calculates the total frequency, arithmetic mean, median, mode and range, and displays the frequency distribution so you can check the data used.

How to use the calculator

  1. Enter the distinct data values, separated by commas.
  2. Enter the frequency for each value in the same order. Leave this field blank if each value occurs once.
  3. Calculate to view the frequency table and statistical summary.

Formulas

Total frequency is Σf. The sum of value multiplied by frequency is Σfx. The mean is Σfx ÷ Σf. The median is the middle observation after arranging the data in order, or the average of the two middle observations when the total count is even. The mode is the value or values with the highest frequency. The range is the largest value minus the smallest value.

Worked example

Suppose the values are 1, 2, 3, 4 and 5, with frequencies 1, 2, 4, 2 and 1. The total frequency is 10. The sum fx is (1×1) + (2×2) + (3×4) + (4×2) + (5×1) = 30. The mean is 30 ÷ 10 = 3. The median is 3 because the fifth and sixth observations are both 3. The mode is 3, and the range is 5 − 1 = 4.

Understanding the statistics

The mean uses every observation and is sensitive to unusually large or small values. The median identifies the centre of the ordered data and is often more representative when the distribution is skewed. The mode identifies the most frequently occurring value and can be useful for categorical or repeated data. The range gives a simple measure of spread but uses only the two extreme values.

Common mistakes and limitations

  • Each frequency must match the value in the same position in the values list.
  • Frequencies must be whole numbers of zero or more.
  • A zero frequency means that value does not contribute to the distribution.
  • This version handles discrete values, not grouped class intervals such as 10–19 or 20–29.
  • The total frequency is limited to 100,000 observations to keep calculations responsive.

Frequently asked questions

Can I leave the frequency field empty?

Yes. Each listed value is then treated as occurring once.

Can a frequency be zero?

Yes, but that value is excluded from the summary because it represents no observations.

What if two values have the same highest frequency?

The distribution is multimodal. The calculator displays all values tied for the highest frequency.
