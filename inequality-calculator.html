Solving inequalities and writing the answer as an interval

An inequality compares two expressions with <, >, ≤ or ≥ instead of an equals sign. Its solution is usually a range of values, not a single number. Type your inequality with one letter and the calculator returns the solution, the interval notation and a graph.

The one rule that is different from equations

Solve an inequality in the same way as an equation, with a single exception: when you multiply or divide both sides by a negative number, reverse the inequality sign. Since −2 × 3 is less than −2 × 1, multiplying 3 > 1 by −2 flips the sign.

Worked examples

A simple linear inequality

2x + 3 < 11. Subtract 3 to get 2x < 8, then divide by 2: x < 4. In interval notation this is (−∞, 4), where the round bracket means 4 itself is not included.

Dividing by a negative

−2x > 6. Dividing by −2 reverses the sign: x < −3, written (−∞, −3).

Including the end point

3x − 2 ≥ 7 gives 3x ≥ 9 and x ≥ 3. A square bracket includes the end point, so the interval is [3, ∞). Another example: 2x + 1 ≤ x + 5 gives x ≤ 4, written (−∞, 4], and 5 − 2x ≤ 1 gives x ≥ 2, written [2, ∞).

A quadratic that is between two roots

x² − 5x + 6 < 0 factorises as (x − 2)(x − 3) < 0. The expression is negative only between the roots, so x > 2 and x < 3, written (2, 3).

A quadratic outside two roots

x² > 9 means x < −3 or x > 3, written (−∞, −3) ∪ (3, ∞). The symbol ∪ joins two separate intervals.

How to read interval notation

  • ( ) round brackets exclude the end point and are used with < and >.
  • [ ] square brackets include the end point and are used with ≤ and ≥.
  • ∞ and −∞ always take round brackets, because they are not numbers you can reach.

Common mistakes

  • Forgetting to reverse the sign after dividing by a negative number.
  • Treating a quadratic like a linear inequality. Find the roots first, then test the intervals.
  • Using the wrong bracket at an end point.
  • Looking for solutions to something like x² + 1 < 0. It has none among real numbers, and the calculator shows a dash.

Frequently asked questions

When do I flip the inequality sign?

Only when multiplying or dividing both sides by a negative number.

What is the difference between ( and [ ?

A round bracket excludes the end point, a square bracket includes it.

How do I solve a quadratic inequality?

Find the roots, mark them on a number line and test which regions make the original inequality true. The calculator does these steps for you.

Can I enter two inequalities at once?

The tool takes one inequality in one letter at a time.
